# tieout (demo)

An AI agent that answers audit-style questions about SEC 10-K filings with
citations, ties out MD&A numbers against XBRL data, and routes uncertain
answers to a human review queue.

This Space runs in demo mode: every answer, tie-out and review replays a
recorded run, so it needs no API key and costs nothing. The source code, the
evaluation results and instructions to run it with your own free API key are
in the GitHub repository.
